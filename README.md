#🌎 Power BI Sales Dashboard – Global Sales Performance
📘 Overview-This Power BI dashboard visualizes global sales performance across multiple countries and product categories.
It provides key business insights through interactive visuals that help analyze cost, revenue, average value, units sold, and profit distribution.

##📊 Key Metrics
Total Cost Price: 2M
Average Value: 145K
Units Sold: 3,083
Profit (%): 61

##📈 Dashboard Highlights
📦 Product Quantity by Category: Donut chart showing distribution across Electronics, Furniture, Groceries, Home Appliances, and Fashion.
🌍 Profit (%) by Country: Bar chart comparing profitability among Germany, USA, UK, Australia, and India.
💰 Revenue by Region: Column chart highlighting sales in South, West, and North regions.
📉 Average Value by Country: Visual comparing average transaction values across countries.
💳 Category by Payment Mode: Pie chart analyzing payment methods such as Debit Card, UPI, Net Banking, Cash, and Credit Card.
📊 Profit by Subcategory: Bar chart displaying top-performing subcategories including Table, Biscuits, Tablet, and Smartwatch.
🎯 Purpose

#To provide an at-a-glance view of global sales data for strategic decision-making, identifying high-performing markets and profitable product categories.

🛠️ Tools & Techniques
Microsoft Power BI Desktop
Data Source: Excel (Sheet1)
Visual Elements: Bar, Pie, and Donut Charts
Filters: Quarter selection (Q1–Q4) and Country filter
DAX Measures for aggregations and performance metrics
