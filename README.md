# 🌎 Power BI Sales Dashboard – Global Sales Performance

## 📘 Overview
This Power BI dashboard presents a comprehensive view of global sales performance across multiple countries and product categories.  
It delivers key business insights through interactive visuals that analyze cost, revenue, average value, units sold, and profit distribution — empowering data-driven decision-making.

## 📊 Key Metrics
- **Total Cost Price:** 2M  
- **Average Value:** 145K  
- **Units Sold:** 3,083  
- **Profit (%):** 61  

## 📈 Dashboard Highlights
- **📦 Product Quantity by Category:** Donut chart displaying distribution across Electronics, Furniture, Groceries, Home Appliances, and Fashion.  
- **🌍 Profit (%) by Country:** Bar chart comparing profitability among Germany, USA, UK, Australia, and India.  
- **💰 Revenue by Region:** Column chart highlighting sales performance across South, West, and North regions.  
- **📉 Average Value by Country:** Visual comparing average transaction values across different markets.  
- **💳 Category by Payment Mode:** Pie chart analyzing payment preferences — Debit Card, UPI, Net Banking, Cash, and Credit Card.  
- **📊 Profit by Subcategory:** Bar chart showcasing top-performing subcategories such as Table, Biscuits, Tablet, and Smartwatch.  

## 🎯 Purpose
To provide an at-a-glance understanding of global sales trends and identify high-performing markets and profitable product categories for strategic planning.

## 🛠️ Tools & Techniques
- **Software:** Microsoft Power BI Desktop  
- **Data Source:** Excel (Sheet1)  
- **Visual Elements:** Bar, Pie, and Donut Charts  
- **Filters:** Quarter selection (Q1–Q4) and Country filter  
- **Measures:** DAX-based calculations for key performance indicators
